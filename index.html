Locate field sites from names

Geocoding APIReverse geocoding
Real problem: field teams record sites by name ("Haramaya University", "Harar Jugol"). Before any GIS analysis they need coordinates. Geocoding turns a list of names into a point layer in seconds.

Tip: click anywhere on the map to reverse-geocode it (coordinates → address). Every site found here is reused in scenario 5.

Show the core code 
const { Geocoder } = await google.maps.importLibrary("geocoding");
const geocoder = new Geocoder();
const { results } = await geocoder.geocode({ address: "Harar Jugol, Ethiopia" });
const loc = results[0].geometry.location;   // lat(), lng()
// reverse: geocoder.geocode({ location: {lat, lng} })

Nearest health facilities and services

Places API (New) · searchNearbyGeometry library
Real problem: where is the nearest hospital or pharmacy to a village or a flood-affected kebele? Planners and NGOs use this to locate service gaps.

Search centre: Maya town (default). Click the map while this tab is open to move it.

Show the core code 
const { Place, SearchNearbyRankPreference } =
      await google.maps.importLibrary("places");
const { places } = await Place.searchNearby({
  fields: ["displayName", "location", "formattedAddress"],
  locationRestriction: { center, radius: 10000 },   // max 50 km
  includedPrimaryTypes: ["hospital"],
  maxResultCount: 10,
  rankPreference: SearchNearbyRankPreference.DISTANCE,
});

Travel time to the referral hospital

Routes API · Route.computeRoutes
Real problem: how long does a patient from each town need to reach Hiwot Fana Specialized Hospital in Harar? Road travel time, not straight-line distance, is what matters for access.

Origins: Maya, Dire Dawa, Babile, Jijiga (approximate town centres). Click the map on this tab to add your own origin.

Show the core code 
const { Route } = await google.maps.importLibrary("routes");
const { routes } = await Route.computeRoutes({
  origin: { lat: 9.400, lng: 42.013 },        // Maya
  destination: "Hiwot Fana Specialized University Hospital, Harar",
  travelMode: "DRIVING",
  fields: ["path", "distanceMeters", "durationMillis"],
});
// routes[0].durationMillis / 60000  → minutes

Elevation profile along a road

Elevation APIRoutes API
Real problem: the Harar → Dire Dawa road drops off the escarpment. The profile shows where gradients are steepest — useful for runoff, road-safety and drainage discussions.
Show the core code 
const { ElevationService } = await google.maps.importLibrary("elevation");
const elevator = new ElevationService();
const { results } = await elevator.getElevationAlongPath({
  path: routePath,          // LatLng array from the route
  samples: 200,             // 2–512 equidistant samples
});
results.map(r => r.elevation);   // metres above sea level
